# Phantom Blade Zero — Arabic Localization

الموقع الرسمي للتعريب العربي للعبة Phantom Blade Zero، إعداد وتعريب AshenKnight.

تتضمن الصفحة مثبّتًا ذكيًا وحزمة تثبيت يدوية كاملة، وكلاهما منشور ضمن GitHub Releases الرسمي للمشروع. الإصدار 1.2 متوافق مع Steam build 26367565 وينظف ملفات الإصدار السابق قبل التثبيت.
